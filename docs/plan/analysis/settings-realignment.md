## Studio Settings order

```text
Studio Profile and Identity
Services and Packages
Default Workspace Information
Plan Information (read-only; Upgrade Plan → Checkout)

```

The plan card is informational, not a configurable capability selector.

## Account Settings order

```text
Account Profile Details
Default Workspace Information
Delete Account
```

Both settings areas retain their existing default-workspace information. In
Account Settings, remove only the duplicate `Active Default` tag and retain
the currently configured workspace text.

## General rules

- Center the Studio Settings/Account Settings tab controls and labels.
- Remove the Settings-page All Workspaces action.
- Keep Studio Name only in Studio Profile and Display Name only in Account
  Profile.
- Preserve existing three-dot and destructive actions.
